## Banner prompt

Create a wide 3:1 editorial banner artwork for a GitHub README for Infinite DJ, a generative electronic music project. Dark charcoal background, sophisticated tactile studio photography mixed with abstract sound sculpture: two brushed black aluminum turntable platters forming a flowing sideways infinity loop, fine luminous warm amber and icy cyan waveform trails connecting the decks and disappearing into depth. Subtle grid and spectral light, restrained nocturnal club atmosphere, strong central composition, beautiful material and lighting, generous dark breathing room at edges. No people, no words, no letters, no logos, no fake application interface. This is conceptual cover artwork, not a screenshot.
