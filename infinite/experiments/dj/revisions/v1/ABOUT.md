# Previous infinite DJ, v1

This snapshot preserves the DJ before the evolving-groove revision: fixed 80-bar song forms, 16-bar handovers, its original instruments and controls. The source hashes are in [snapshot.json](snapshot.json). The archived README is historical; use this launcher to play the snapshot from the repository directory:

```sh
/Applications/SuperCollider.app/Contents/MacOS/sclang -D infinite/experiments/dj/revisions/v1/run.scd 2600 128
```

Close another DJ performance first; both use port 57134. The snapshot defines the same IDE variables as the current DJ. STOP/START and the original controls are retained. No recording starts automatically.
