# Lead-forward v4 snapshot

This preserves the instrument palettes, recurring lead melody and automatic
multi-bar stutter heard before the bass-led arrangement. README.md is historical.

Run from the repository directory:

~~~sh
sclang -D infinite/experiments/dj/revisions/v4/run.scd 2600 128
~~~

Close another DJ session first; both use port 57134. The v4 AAC previews in audio/
remain separate from the new v5 recordings.
